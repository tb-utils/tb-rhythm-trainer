TB Rhythm Trainer

Version: 6f · Created: 2026-09-23 · Updated: 2026-09-25 · License: MIT
A simple instrument practice tool that gradually reveals the next measure while you play the completed previous measure.
Display:
PLAY = the completed measure to play now. NEXT = the next measure currently being revealed.
[root + separator + chord suffix] = chord. Examples: [C] = C major, [C5] = C power chord, [C4:5] = C power chord rooted at C4.
A label such as C or C5 by itself = single note.
- = rest. Depending on the instrument, you may let the previous sound sustain or mute it.
Keyboard: Space = Start/Stop, p = Pause/Resume. Pause keeps the current position; Resume continues from the same measure.
Ready
Presets are stored only in this browser's localStorage. Selecting a preset loads it immediately. The selected Preset and Preset name are also restored the next time you open the app.
Preset storage / file access:
Normal preset storage uses only this browser's localStorage.
Import reads only a JSON file that you explicitly select.
Export creates a standard browser download, with tb-rhythm-trainer-presets.json as the suggested filename. The browser decides how and where the file is saved, and may ask you to choose a location.
The app does not directly choose or write to arbitrary file paths. This app does not use the File System Access API and cannot browse or modify arbitrary files on your computer.
Tempo. Default: 120. The output interval is 60 / (BPM × subdivision) seconds.
Number of subdivisions per beat. Default: 1.
1 = one event per beat, 2 = eighth-note subdivision, 3 = triplets, 4 = sixteenth-note subdivision.
Pattern for one measure. If left blank, it becomes 4 × subdivision copies of 2.
0: rest, and suppress the metronome click for that beat
1: rest
2: single note
3: single note or rest
4: chord
5: chord or rest
6: chord or single note
7: chord, single note, or rest
The pattern length does not have to be a multiple of subdivision.

Example: subdivision=2, pattern=41333331
→ Generates one measure in eighth-note subdivisions: chord / rest / note-or-rest / …
Insert a | separator every N events. Default: 0. 0 means no separators.
Probability of generating a rest for pattern values 3 / 5 / 7. Default: 0.25 (25%). Pattern values 0 / 1 are always rests.
Optional text inserted between the root label and suffix. Leave blank for standard forms such as [C7], or if you prefer to include punctuation directly in CHORD_SUFFIXES. For example, NOTES=C4, separator=:, suffix=7 → [C4:7].
Labels used for single-note prompts and also as chord roots. They are treated as plain text, so you can restrict them to a scale, include octave numbers such as C4 C#4 D4 ..., or use non-pitched labels. For a drum kit, for example: Kick Snare HiHat Tom1 Tom2 Crash Ride.
One entry per line. (major) or "" is treated as an empty suffix, producing [C].
An entry without a root filter applies to all NOTES roots, for example 7.
To restrict an entry to specific roots, use suffix{root1, root2, ...}, for example 7{E, A, B}. Whitespace is allowed around the root filter and around comma-separated root labels inside {...}. Do not use whitespace inside the suffix itself or inside a root label. Root labels must match NOTES exactly.
E-blues-oriented example: NOTES=E G A Bb B D; CHORD_SUFFIXES=7{E, A, B}, 5, :bend{G, A, Bb, B, D}.
Custom technique example: :harmonic{E, A, B}.
For example, :harmonic { E , A , B } is valid, while natural harmonic { E, A } is not. You may freely add, remove, or replace entries. With an empty Chord separator, punctuation can be included directly in the suffix.
